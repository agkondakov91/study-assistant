# 📂 Этап 1. Каталог материалов

**После лекции 8** «Файлы, JSON, исключения»
**Проверка:** `uv run pytest -m stage1`

---

## 🎯 Что делаем и зачем

Программе нужны данные, и они должны лежать не в коде, а в файлах. Иначе
добавить конспект — значит правкой программы, а отдать материалы коллеге —
значит отдать всю программу.

На этом этапе появляется первый рабочий слой: чтение папки с конспектами
и сохранение результата в JSON.

## 📦 Что появится в проекте

`study_assistant/catalog.py` — пять функций:

| Функция | Что делает |
|---|---|
| `read_material(path)` | Разбирает один файл: заголовок, строки, слова, символы |
| `build_catalog(directory)` | Собирает описания всех `.md` файлов папки |
| `save_catalog(catalog, path)` | Записывает каталог в JSON |
| `load_catalog(path)` | Читает каталог из JSON |
| `print_report(catalog)` | Печатает отчёт |

## 📝 Задание

Код, который нужно написать, помечен в `study_assistant/catalog.py`
комментариями `TODO`. Сигнатуры и докстринги менять не нужно — по ним написаны
тесты.

### 1. `read_material(path)`

Возвращает описание файла с пятью характеристиками:

| Что | Как считается |
|---|---|
| имя файла | `path.name` |
| заголовок | первая **непустая** строка; если таких нет — `EMPTY_TITLE` |
| строки | количество **непустых** строк |
| слова | `len(text.split())` |
| символы | `len(text)` |

> ⚠️ **Осторожно с пустыми строками.** В файлах материалов есть пустые строки
> внутри текста. `lines` считает только непустые, а `chars` — все символы,
> включая переводы строк. Это разные числа, и тесты на это смотрят.

> 💡 Файл `materials/empty.md` пустой — это не ошибка, а проверка. Для него
> заголовок должен быть `(пустой файл)`, а счётчики нулевыми. Отдельная проверка
> «а вдруг файл пустой» при этом не нужна: если написать честно, всё посчитается
> само.

### 2. `build_catalog(directory)`

Собирает описания всех `.md` файлов **в алфавитном порядке имён**.

Если папки не существует — порождает `FileNotFoundError` с текстом
`f"Папка {directory} не найдена"`.

> ⚠️ **`glob()` не гарантирует порядок** — он зависит от файловой системы.
> Оберните в `sorted()`, иначе у вас и у одногруппника результат будет разным
> при одинаковых данных.

> 💡 **Почему `raise`, а не `print`.** Функция не знает, что правильно сделать
> при отсутствии папки: в консоли — показать сообщение, в боте — ответить
> пользователю, в тесте — засчитать неудачу. Она только сообщает о проблеме,
> а решает вызывающий код. Посмотрите, как это сделано в `main.py`.

### 3. `save_catalog(catalog, path)`

Записывает каталог в JSON.

> ⚠️ **Два аргумента `json.dump`, без которых тесты не пройдут:**
> - `ensure_ascii=False` — иначе русский текст станет `"Фу..."`;
> - `indent=2` — иначе всё запишется одной строкой, и в Git не будет видно правок.

### 4. `load_catalog(path)`

Читает каталог из JSON. **Ошибки не обрабатывает:** нет файла — пусть падает
с `FileNotFoundError`, повреждён — с `json.JSONDecodeError`. Ловит их `main.py`.

### 5. `print_report(catalog)`

Печатает отчёт. Формат — ровно такой, обратите внимание на отступы в два
и четыре пробела:

```
Файлов в каталоге: 4

  data_structures.md
    заголовок: Структуры данных
    строк: 5, слов: 36, символов: 250
  empty.md
    заголовок: (пустой файл)
    строк: 0, слов: 0, символов: 0
  functions.md
    заголовок: Функции
    строк: 3, слов: 15, символов: 112
  python_basics.md
    заголовок: Основы Python
    строк: 4, слов: 26, символов: 198

Всего слов во всех материалах: 77
```
