# 🗺️ Этапы проекта

Проект собирается постепенно. Каждый этап добавляет новый слой, а написанное
раньше продолжает работать без правок — или правится осознанно, когда меняется
контракт.

Порядок важен: каждый этап опирается на предыдущий.

---

## Как устроено задание каждого этапа

В папке этапа лежит `README.md` с одинаковой структурой:

- **Что делаем и зачем** — какую задачу решает этап
- **Что появится в проекте** — какие файлы и функции
- **Задание** — по пунктам, с подсказками
- **Проверка** — какую команду запускать
- **Критерии оценивания** — за что ставятся баллы

Код, который нужно написать, помечен в файлах пакета комментариями `TODO`.
